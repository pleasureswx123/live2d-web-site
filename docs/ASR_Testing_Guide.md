# ASR持续模式测试指南

## 测试目标

验证从 `startContinuousASR` 到 `stopContinuousASR` 过程中内容采集的完整性和准确性。

## 测试环境

1. 确保WebSocket连接正常
2. 确保ASR服务可用
3. 确保麦克风权限已授权
4. 使用 `ASRTestComponent` 进行测试

## 测试场景

### 1. 连续说话测试

**目标**: 验证连续说话时内容的完整采集

**步骤**:
1. 点击"开始持续ASR"按钮
2. 连续说话："今天天气很好，我想出去走走，顺便买点东西回来"
3. 点击"停止持续ASR"按钮
4. 检查输入框中的完整内容

**预期结果**:
- 输入框显示完整的句子
- 测试日志显示所有识别过程
- 持续模式详情显示累积文本

### 2. 间断说话测试

**目标**: 验证间断说话时片段的正确分割和累积

**步骤**:
1. 点击"开始持续ASR"按钮
2. 说话："今天天气很好" [停顿3秒]
3. 继续说话："我想出去走走" [停顿3秒]
4. 继续说话："顺便买点东西"
5. 点击"停止持续ASR"按钮

**预期结果**:
- 输入框显示："今天天气很好 我想出去走走 顺便买点东西"
- 持续模式详情显示3个片段
- 每个片段内容正确

### 3. 快速停止测试

**目标**: 验证说话过程中立即停止的内容保存

**步骤**:
1. 点击"开始持续ASR"按钮
2. 开始说话："今天天气很好，我想..."
3. 立即点击"停止持续ASR"按钮

**预期结果**:
- 输入框显示已识别的部分内容
- 不会丢失已识别的内容

### 4. 长时间说话测试

**目标**: 验证长时间持续说话的稳定性

**步骤**:
1. 点击"开始持续ASR"按钮
2. 持续说话30秒以上
3. 点击"停止持续ASR"按钮

**预期结果**:
- 所有内容都被正确采集
- 系统保持稳定
- 内存使用正常

## 调试信息检查

观察以下关键日志：

### 测试组件显示

在ASRTestComponent中检查：

1. **连接状态**: WebSocket和ASR都应为"已连接"
2. **录音状态**: 应显示"录音中"
3. **持续模式**: 应显示"激活"
4. **累积文本**: 实时显示累积的完整文本
5. **片段数量**: 显示识别的片段数量
6. **所有片段**: 列出每个识别的片段

## 常见问题排查

### 1. 内容不完整

**症状**: 停止后输入框内容缺失部分

**检查**:
- 查看控制台是否有"使用持续模式累积文本"日志
- 检查片段数组是否包含所有片段
- 确认最后的识别结果是否被处理

**解决**:
- 增加停止前的等待时间
- 检查网络连接稳定性

### 2. 片段重复

**症状**: 同一内容被重复添加

**检查**:
- 查看片段数组是否有重复内容
- 检查时间间隔判断逻辑

**解决**:
- 调整片段识别的时间阈值
- 检查重复过滤逻辑

### 3. 片段分割错误

**症状**: 应该分开的内容被合并，或应该合并的内容被分开

**检查**:
- 查看时间间隔日志
- 检查isFinal标志

**解决**:
- 调整时间阈值（当前为2000ms）
- 优化片段识别逻辑

## 自动化测试

可以编写自动化测试脚本：

```javascript
// 模拟ASR结果事件
const simulateASRResult = (text, isFinal, delay = 0) => {
  setTimeout(() => {
    window.dispatchEvent(new CustomEvent('asrResult', {
      detail: { text, isFinal, confidence: 0.9 }
    }))
  }, delay)
}

// 测试场景
const testContinuousMode = async () => {
  // 开始持续模式
  startContinuousASR()
  
  // 模拟多个识别结果
  simulateASRResult('今天天气', false, 1000)
  simulateASRResult('今天天气很好', true, 2000)
  simulateASRResult('我想出去', false, 4000)
  simulateASRResult('我想出去走走', true, 5000)
  
  // 停止并检查结果
  setTimeout(() => {
    stopContinuousASR()
    // 验证结果
  }, 6000)
}
```

通过这些测试，可以确保ASR持续模式的内容采集功能正常工作。
